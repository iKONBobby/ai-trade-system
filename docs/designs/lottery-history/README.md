# 双色球与大乐透历史开奖走势

直接在浏览器打开 `index.html`，查看按期排列的开奖号码与遗漏表。支持切换彩种、按年份筛选、每页 30 期翻页和显示／隐藏遗漏。

数据来源为 [500彩票网双色球历史开奖](https://datachart.500.com/ssq/history/history.shtml)和[大乐透历史开奖](https://datachart.500.com/dlt/history/history.shtml)，与 [Justdoitfor/my-lottery-data](https://github.com/Justdoitfor/my-lottery-data) 镜像逐期交叉核对。期号、日期、开奖号码一致；校验记录见 `validation.json`。

遗漏从各彩种首期起累计，开出时归零，未开出时加一，不随年份筛选或翻页重置。和值、跨度、区间比、奇偶比均仅统计红球／前区。双色球按 01–11、12–22、23–33 分区，大乐透按 01–12、13–24、25–35 分区。

已校验号码个数、范围、组内重复、升序、期号唯一性、日期顺序及年内期号连续性；已验证彩种切换、年份筛选、翻页、返回最新与遗漏开关。

应用内入口：随机实验室顶部的「历史开奖走势」，路由为 `/number-lab/history`。应用版本使用原生 React 表格及项目主题，不依赖可视化运行时；彩种、年份和页码保存在 URL 中。数据文件为 `apps/web/src/data/lottery-history.json`，目前仍为上述快照，未接入后端自动刷新流程。

本目录的 `index.html` 保留为独立展示快照，使用可视化运行时的 CDN 资源，首次打开需联网。
