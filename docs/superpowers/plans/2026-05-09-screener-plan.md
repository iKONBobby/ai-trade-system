## Scope Summary

**MVP 核心**:
- 因子引擎架构（方案 B）
- 3 个预设策略（均线多头排列、RSI 超跌反弹、放量突破）
- 全市场扫描（~4000 只 A 股，3 分钟内）
- 完整版结果卡片（代码/现价/涨跌/得分/因子标签/sparkline）
- 点击卡片跳转单股分析页

**已接受扩展**:
- 策略表现统计
- CSV 导出
- 收藏候选池（localStorage）
- 多策略对比扫描

**推迟到 v1.1**:
- 定时自动扫描
- AI 一句话点评
- 实时行情刷新
- 历史扫描记录

## 实现顺序

1. 类型定义 (shared types + screener types)
2. 因子注册表 (factors.ts → indicators.ts 映射)
3. 策略配置 (strategies.ts → 3 个 MVP 策略 JSON)
4. 因子引擎 (engine.ts → 并发扫描 + 任务管理)
5. API 路由 (screener.ts → 注册到 Express)
6. 前端页面 (screener/page.tsx + ScreenerCard + SparklineSVG)
7. 候选池 (WatchlistPanel + localStorage)
8. 策略统计 + CSV 导出
9. 多策略对比
